# 📈 Gerboo Trading Academy

Gerboo Trading Academy is a modern online learning platform designed to help beginners and experienced traders learn Forex and Cryptocurrency trading through structured courses, quizzes, progress tracking, and certificates.

---

## 🚀 Features

- Responsive Landing Page
- User Authentication (Coming Soon)
- Student Dashboard (Coming Soon)
- Trading Courses
- Interactive Quizzes
- Certificates
- Progress Tracking
- Firebase Integration (Coming Soon)

---

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Firebase (Planned)
- Git & GitHub
